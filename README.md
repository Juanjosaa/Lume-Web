# Lume · Maquillaje consciente en Cali

Sitio web de **Lume**, marca de maquillaje ecológico de Cali, Colombia.
Proyecto universitario de la materia *Fundamentos de Mercadeo*.

## Estructura

```
index.html      → contenido de todas las secciones
css/styles.css  → estilos (colores en las variables de :root)
js/main.js      → menú, animaciones, acordeón y formulario
img/            → ilustraciones de ejemplo (reemplazables por fotos reales)
```

## Cómo cambiar las imágenes

Guarda tu foto en `img/` y cambia el `src` de la imagen en `index.html`
(por ejemplo `img/rubor.svg` → `img/rubor.jpg`).

## Publicación

Sitio estático (HTML, CSS y JavaScript), sin instalación ni compilación.
Se publica en Vercel importando este repositorio con la configuración por defecto.
